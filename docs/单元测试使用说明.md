# 单元测试使用说明

## 环境要求

- JDK 17+
- Maven 3.6+（项目自带 `mvnw` 无需全局安装 Maven）

测试使用 **H2 内存数据库**，无需安装或配置 MySQL，无需外部依赖即可运行。

## 快速开始

### 运行全部测试

```bash
# Windows
mvnw.cmd test

# Linux / macOS
./mvnw test
```

### 运行指定测试类

```bash
mvnw.cmd test -Dtest=UserServiceTest
```

### 运行指定测试方法

```bash
mvnw.cmd test -Dtest=UserServiceTest#testLoginSuccess
```

### 运行多个测试类

```bash
mvnw.cmd test -Dtest=UserServiceTest,SysDictServiceTest
```

## 测试类说明

### 1. JwtUtilTest — JWT 工具类测试（纯单元测试）

**不依赖 Spring 容器**，使用 `ReflectionTestUtils` 注入配置，速度最快。

| 测试方法 | 说明 |
|---|---|
| `testGenerateToken` | 验证能正常生成 token 字符串 |
| `testParseToken` | 验证 token 解析后 Claims 包含正确的 userId、username、role |
| `testGetUsernameFromToken` | 验证从 token 中提取用户名 |
| `testGetUserIdFromToken` | 验证从 token 中提取用户 ID |
| `testGetRoleFromToken` | 验证从 token 中提取角色 |
| `testTokenNotExpired` | 验证新生成的 token 未过期 |
| `testValidateToken` | 验证合法 token 校验通过 |
| `testValidateInvalidToken` | 验证非法/空/无效 token 校验不通过 |

### 2. ResultTest — 统一返回结果测试（纯单元测试）

**不依赖 Spring 容器**，直接测试 `Result` 工具类的静态工厂方法。

| 测试方法 | 说明 |
|---|---|
| `testSuccess` | 无参 success() 返回 code=200, message="操作成功" |
| `testSuccessWithData` | success(data) 返回携带数据的成功结果 |
| `testSuccessWithMessageAndData` | success(msg, data) 自定义消息 |
| `testError` | error(msg) 返回 code=500 |
| `testErrorWithCode` | error(code, msg) 自定义错误码 |

### 3. UserServiceTest — 用户业务层测试（集成测试）

需要 Spring 容器，使用 `@SpringBootTest` + `@Transactional`（每个测试后自动回滚）。

| 测试方法 | 说明 |
|---|---|
| `testLoginSuccess` | 正确用户名密码登录成功，返回密码字段为 null |
| `testLoginFailWrongPassword` | 错误密码登录返回 null |
| `testLoginFailNonExistUser` | 不存在的用户登录返回 null |
| `testFindById` | 按 ID 查找用户 |
| `testFindAll` | 查询全部用户，不少于 3 条 |
| `testFindAllByUsername` | 按用户名模糊搜索 |
| `testRegisterSuccess` | 注册新用户成功，角色默认为 nurse，密码字段不返回 |
| `testRegisterDuplicateUsername` | 重复用户名注册抛出 RuntimeException |

### 4. SysDictServiceTest — 数据字典业务层测试（集成测试）

需要 Spring 容器，`@Transactional` 自动回滚。

| 测试方法 | 说明 |
|---|---|
| `testFindByType` | 按类型查询字典，risk_level 有 3 条 |
| `testFindAllTypes` | 查询所有字典类型，包含 risk_level |
| `testAddAndFind` | 新增字典后按 ID 查询验证 |
| `testUpdate` | 更新字典值后验证 |
| `testDelete` | 新增后删除，验证 findById 返回 null |

### 5. UserControllerTest — 用户接口层测试（集成测试）

需要 Spring 容器 + MockMvc，使用 `@AutoConfigureMockMvc` 模拟 HTTP 请求。

| 测试方法 | 说明 |
|---|---|
| `testLoginSuccess` | POST /api/user/login 正确凭据返回 token + user 信息 |
| `testLoginFailWrongPassword` | 错误密码返回 code=401 |
| `testRegisterSuccess` | 注册成功返回 username=nurse, role=nurse |
| `testRegisterDuplicate` | 重复注册返回 code=400 |
| `testGetUserListWithoutToken` | 无 token 访问用户列表返回 401 |
| `testGetUserListWithToken` | 先登录获取 token，再带 Bearer token 访问列表，返回 >= 3 条 |

## 测试配置说明

### `application-test.properties`

- H2 数据库连接：`jdbc:h2:mem:testdb;MODE=MySQL`，兼容 MySQL 语法
- `DB_CLOSE_DELAY=-1`：JVM 运行期间保持数据库不关闭
- 每次启动自动执行 schema-h2.sql 建表和 test-data.sql 插入数据

### `schema-h2.sql`

定义 7 张表（与生产 MySQL 结构一致）：
`sys_user`, `elder_health_record`, `cognitive_assessment`, `intervention_plan`, `intervention_execution`, `sys_dict`, `risk_warning`

### `test-data.sql`

种子数据：
- 3 个用户：admin(管理员)、doctor1(医生)、nurse1(护士)
- 3 条老人健康档案
- 3 条认知评估记录
- 3 条数据字典项（risk_level）

## 编写新测试

对于需要 Spring 容器的测试类，遵循以下模板：

```java
@SpringBootTest
@ActiveProfiles("test")
@Transactional              // 测试后自动回滚，不污染数据
class XxxServiceTest {

    @Autowired
    private XxxService xxxService;

    @Test
    void testMethod() {
        // 直接调用方法，断言结果
    }
}
```

对于不依赖 Spring 的纯单元测试，直接使用 `new` + JUnit 5 断言即可，速度更快。

## 常见问题

**Q: 测试报 "Table not found"？**
A: 检查 `schema-h2.sql` 中是否包含对应表的建表语句，确认 SQL 语法兼容 H2。

**Q: 测试报 "No qualifying bean"？**
A: 检查被测类是否有 `@Service`/`@Component` 注解，以及 mapper 是否有 `@Mapper` 注解。

**Q: 测试之间数据互相干扰？**
A: 集成测试类上已加 `@Transactional`，每个测试方法结束后自动回滚。Service 层测试回滚整个数据库，Controller 层使用 MockMvc 也受事务管理。
