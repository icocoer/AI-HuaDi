### 项目的启动和停止
- 在项目根目录双击start.bat，并等待几秒后启动项目
- 在项目跟目录双击stop.bat，并等待几秒后停止项目
- 以上操作均在文件夹内进行，使用IDEA点击是无效的

### 前端准备工作
- 在idea的控制台输入一下命令
- cd frontend 确保进入前端文件夹
- npm install 安装前端必要组件
- npm dev run 验证是否正常工作

### 数据库
- 确保本地安装了MySQL
- 在命令行输入命令
- `cmd /c "mysql -u root -p123456 cognitive_health < src/main/resources/database.sql"`
- 自动完成建表工作
- 数据库名：cognitive_health
